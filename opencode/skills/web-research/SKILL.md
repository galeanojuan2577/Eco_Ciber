# Web Research

Use these tools for web research:

## ScrapeGraphAI
- `SmartScraperGraph` - Natural language scraping (single page)
- `SearchGraph` - Search + scrape top results
- `ScriptCreatorGraph` - Generate Python scraper scripts

## Crawl4AI (Docker)
- API: http://localhost:11235/crawl
- For deep crawling with Markdown output

## Playwright MCP
- Browser automation for visual scraping
- Screenshots, click, fill, navigation
