# ECC+ Ecosystem Tools

## Token Optimization
- **Headroom** proxy running on port 8787
- Configure OPENAI_BASE_URL=http://127.0.0.1:8787/v1 to use it

## Agent-Browser
- Rust-based browser automation (~7MB)
- MCP tools: open, click, snapshot, screenshot, fill

## local-rag (@13w/local-rag)
- Distributed semantic memory + code RAG as MCP plugin
- Semantic code search across your projects

## Docker Services
- Crawl4AI: http://localhost:11235
- MinIO: http://localhost:9001
- Portainer: http://localhost:9443
- Uptime Kuma: http://localhost:3001
- Firecrawl: http://localhost:3002
