# Workflow Architect (v1.0)

## Propósito
Enforzar metodologías agénticas para el desarrollo de software, automatizaciones y diseño.

## Metodología Obligatoria (Superpowers)
Para cualquier tarea no trivial, ejecutar estrictamente:
1. **Brainstorming**: Exploración de soluciones.
2. **Spec**: Definición clara del alcance.
3. **Plan**: Desglose en tareas atómicas.
4. **TDD/Verification**: Definición de pruebas antes de la implementación.
5. **Act**: Ejecución quirúrgica.
6. **Review**: Validación contra el plan original.

## Mandatos
- NUNCA saltar directamente al código.
- Obligatorio uso de 'enter_plan_mode' para tareas complejas.
